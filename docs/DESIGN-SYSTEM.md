# Sistema de Design

Decisões visuais estabelecidas para o projeto `encurtador-url`, reaproveitadas por toda feature
nova com UI — evita redefinir paleta/tom a cada rodada de wireframes.

## Paleta de cores

- **Primária**: azul (confiança/tecnologia, comum em ferramentas utilitárias).
- **Secundária/neutra**: tons de cinza para o restante da interface (fundo, texto, bordas).
- Sem hex específicos definidos ainda — a skill `design` escolhe os tons dentro dessa direção
  (azul + neutro) a cada rodada; se um hex exato for fixado depois, registre aqui.

## Tom/estilo visual

Minimalista: interface limpa, poucos elementos, foco total na ação principal (colar URL → receber
URL encurtada). Evitar elementos decorativos que disputem atenção com o campo principal.

## Tipografia

Sem preferência explícita — usar uma sans-serif legível e moderna (ex.: Google Fonts) escolhida
pela skill `design` a cada rodada.
